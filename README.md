# Levelap Games landing page

A concise English-language studio and games showcase based on the Levelap Games pitch deck.

## Structure

- `index.html` - page content and metadata
- `styles.css` - visual design and responsive layout
- `script.js` - scroll progress indicator
- `assets/` - original game artwork from the pitch deck

Open `index.html` directly or serve the folder with any static web server.
